Music sequencer

One bar of sixteen steps, voiced with square waves and noise like the 1978 board. Pattern A is the winning music, B the losing music; the game's tension decides which plays, how much percussion is heard, and how fast. Nothing plays until a pattern has notes.

Sound lab

Name each file exactly like its event id, for example alien_destroyed.wav (any common audio format; capital letters do not matter, anything else does). Then drop the files, or the whole folder, anywhere on this panel and they load themselves. A file with the same name replaces the sound that is loaded; one sound per event. Dropping a single file directly onto an event loads it there whatever it is called; several files or a folder dropped anywhere, an event included, go by name. Save pack bundles everything loaded here, with its settings, into one .json file that Open pack restores. Until a sound is loaded, an event plays a rough built-in tone so the game is never silent; untick Built-in tones at the top of the page to hear only the loaded sounds. Nothing is uploaded; files stay in this browser tab.
